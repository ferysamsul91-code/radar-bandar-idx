Publikasi REKAP online

Radar Bandar IDX • kirim ringkasan REKAP harian ke repo GitHub Anda, terenkripsi, untuk landing page.

Pengecualian aturan "tanpa mengirim data ke luar". Bila diaktifkan, setiap hari bursa setelah data penutupan lengkap (atau setelah 18:00), ekstensi mengirim ringkasan REKAP (daftar institusi & asing beli/jual, deteksi institusi beli) ke repo GitHub yang Anda isi di bawah. Isinya dienkripsi dengan kata sandi Anda sebelum keluar dari komputer; tanpa kata sandi, orang lain hanya melihat data acak. Token dan kata sandi disimpan lokal di Chrome Anda dan hanya dipakai di halaman ini dan service worker ekstensi, tidak pernah di halaman Stockbit. Bukan rekomendasi beli/jual.
Repo landing page Anda, mis. pemilik/radar-bandar-idx. File ditulis ke data/days/TANGGAL.enc.json.
Buat di github.com/settings/personal-access-tokens/new:
  1. Repository access: Only select repositories → pilih repo landing page saja.
  2. Permissions → Repository permissions → Contents: Read and write (lainnya biarkan).
  3. Expiration sesuai keinginan; saat kedaluwarsa, buat token baru dan tempel di sini.
Dipakai untuk mengenkripsi data dan untuk membukanya di landing page. Simpan baik-baik: kata sandi yang hilang tidak bisa dipulihkan; data lama hanya terbuka dengan kata sandi lamanya.
